# Dataset

The complete 1,800-image dataset is provided in `blood_cell_dataset.zip` (450 JPG images for each class: Eosinophil, Lymphocyte, Monocyte, and Neutrophil).

Extract the archive into this `dataset` directory before running `train_model.py`. The extracted folder layout should be `dataset/Eosinophil/`, `dataset/Lymphocyte/`, `dataset/Monocyte/`, and `dataset/Neutrophil/`.
