Blood Cell Dataset Overview

The dataset contains 1,800 microscopic blood cell images evenly categorized across the 4 major leukocyte classes.

📊

Dataset Structure

Images are stored in a clean directory hierarchy with 450 authentic images per class:

dataset/
├── Eosinophil/   (450 images)
├── Lymphocyte/   (450 images)
├── Monocyte/     (450 images)
└── Neutrophil/   (450 images)
🔬

Class Characteristics

  • Eosinophil: Bilobed nucleus, reddish-orange granules.
  • Lymphocyte: Large spherical nucleus, thin cytoplasmic rim.
  • Monocyte: Kidney-shaped nucleus, extensive gray-blue cytoplasm.
  • Neutrophil: 3-5 lobed nucleus, lilac cytoplasmic granules.

Image Preprocessing Pipeline

Every microscopic blood smear image undergoes rigorous standardization prior to CNN training and inference.

Step 1

RGB Conversion

Loads raw microscopic imagery via Pillow and verifies standard 3-channel RGB color space format.

Step 2

Spatial Resizing (128 × 128)

Resizes arbitrary microscopic camera resolutions to fixed 128 × 128 pixels using bilinear interpolation.

Step 3

Pixel Normalization [0, 1]

Scales raw integer pixel values $(0 \dots 255)$ to continuous floating-point tensors in the range [0.0, 1.0].

Step 4

Categorical Label Encoding

Maps categorical class names into numerical target vectors: Eosinophil (0), Lymphocyte (1), Monocyte (2), Neutrophil (3).
